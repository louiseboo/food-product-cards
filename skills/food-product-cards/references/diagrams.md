# Exploded diagrams

1. Read the photo and full ingredient brief. List only confirmed components and confirmed order; distinguish an ingredient relation from manufacturing order in working notes.
2. Generate a cream-background studio exploded view with physically separate layers, consistent camera angle and scale, no typography, no added ingredients. Preserve the supplied product's silhouette, bread colour and fillings. Keep cake tips facing right.
3. Inspect actual pixels: count layers, check visible gaps, eliminate fused layers, ensure toppings/jam separate where required, and check that nothing is cropped.
4. Add external HTML labels, one per verified component/group. Set y percentages from the finished image, not an assumed evenly spaced grid. Inspect long labels for collisions.
5. Keep the original photo in its own panel. Never quietly replace it with a generated image.

Prompt scaffold: “Using the supplied product photo and these verified components: [components], create a vertically exploded studio food image. Separate [layers] with clear air gaps. Preserve [shape/colour/angle]. Plain warm cream background. No text, arrows, plates, extra ingredients or decorative additions. This is an explanatory ingredient image.”

If order is unknown, resolve it or use a clearly scoped ingredient relationship in working records; never invent the assembly sequence. The final card must not include process disclaimers.
